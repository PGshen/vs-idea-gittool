# UI text translations

The UI language follows the VS Code display language (*Configure Display Language*). English is the source language
and needs no files; other languages:

| File | Contents |
|---|---|
| `package.nls.<lang>.json` | command titles, settings, views, menus (contrib/*.json). `package.nls.json` (English) is generated by `npm run contrib`, which replaces the text in package.json with `%key%` placeholders and reports keys missing in the translations |
| `l10n/bundle.l10n.<lang>.json` | text of the extension (`vscode.l10n.t`) and the webviews (`t` from `src/webview/lib/l10n.ts`), keyed by the English text |

`npm run l10n` lists strings without translation; `npm run l10n -- --strict` fails on them.

## Writing translatable code

- Host: `vscode.l10n.t('Pushed {0} commits to {1}', n, branch)`. Webviews: `import { t } from '../lib/l10n'` and `t(...)` with the same syntax.
- The message is always a plain string literal (no template literals, no concatenation, no variables), so that it can be checked.
  Put values in `{0}`, `{1}`, …; the translation may reorder them.
- Translate where the literal is written: a host string sent to a webview is translated by the host, and the webview shows it as is.
- Whole sentences, not fragments: `t('Delete {0} files?', n)`, not `t('Delete') + ' ' + n + ' ' + t('files?')`.
  Plurals: one key per form (`'{0} file'`, `'{0} files'`).
- Do not translate identifiers: command ids, setting keys, RPC methods, action ids, git arguments, values that are
  compared, persisted or parsed. When a label is also compared (a pressed message button), keep the translated label in a variable and compare with it.
- Strings needed at module load are fine: the bundle is available synchronously.

## zh-cn style

Follow the wording of the IntelliJ IDEA Chinese language pack (the English text follows IntelliJ's GitBundle / VcsBundle).

- Put a space between Chinese and Latin letters, digits or placeholders: `推送 {0} 个提交到 {1}`, `使用 Git Blame 注解`.
- Keep `…`, keyboard shortcuts, and proper names: Git, HEAD, GPG, IntelliJ, IdeaGitTool, VCS, SSH, URL.
- Avoid personal pronouns where possible; use 您 when one is needed.
- Use Chinese full-width punctuation in Chinese sentences (，。：？！（）), but keep ASCII punctuation around code, paths and placeholders that need it.
